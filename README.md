# 24th CVO Ammo Logistics
The goal of this mod is to expand the repacking functionality by introducing the consumable ammo items that are used to refill the magazines. The mod features the simple, basic and complex ammo modes, the ability to convert empty magazines into their variants, refilling and unloading magazines using ammo, CBA settings to fine tune your gaming experience.
